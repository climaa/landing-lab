# Welcome

This Storybook belongs to landing-lab, a public lab on a fictional brand, Taskbloom. One
category page is built twice: `/before` draws every star as its own unnamed image, `/after`
draws each rating as one named element with `RatingStars`. Both are measured side by side,
and an SEO guard, visual regression and an acceptance suite keep the fix from coming back.

## Start here

- [Quality Gates → Overview](?path=/docs/docs-quality-gates-overview--docs): what runs on
  every change, and what each check protects.
- [Rating Stars](?path=/docs/docs-atomic-design-rating-stars--docs): the component, and
  what it changed, measured.
- [/compare](https://landing-lab.carloslima.dev/compare?utm_source=storybook): both pages,
  measured live in your browser.

The components themselves are in the sidebar, from Atoms to Templates.
